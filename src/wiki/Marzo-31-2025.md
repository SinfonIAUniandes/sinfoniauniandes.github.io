**4. Introducción y Configuración de Docker:**

- **Verificación de Instalación:** Se procedió a verificar si los asistentes tenían Docker instalado en sus portátiles.
  - **Linux:** Se comprobó la instalación buscando "docker" en la terminal. Se mencionó la necesidad de realizar los pasos de "post-instalación" de Docker para Linux para poder usarlo sin `sudo`. Se indicaron los pasos siguiendo la documentación oficial (buscar "Linux post install docker"). Una vez hecho, `docker ps` debería funcionar.
  - **Windows:** Se confirmó que uno de los asistentes usaba Windows. Se indicó que la instalación en Windows es un poco más "pesada" pero factible con un buen PC.
- **Explicación Docker en Windows vs. Linux:**
  - Docker se construyó sobre sistemas operativos tipo Unix (como Linux).
  - En Linux, Docker se integra de forma nativa y funciona muy bien.
  - Windows no es Unix, por lo que Docker en Windows necesita una capa de virtualización. Utiliza **WSL (Windows Subsystem for Linux)**. Docker monta un sistema Unix virtualizado y corre sobre él.
  - Esto consume más recursos en Windows.
  - **Importante:** No se deben tener múltiples sistemas virtualizados activos al mismo tiempo en Windows (ej. Docker y una máquina virtual de Ubuntu completa) porque puede generar conflictos. Hay que elegir uno o gestionar bien WSL. Activar WSL es el primer paso para Docker en Windows.
- **Instrucciones de Instalación de Docker en Windows:**
  1. **Activar WSL:** Abrir PowerShell como administrador y ejecutar el comando: `wsl --install`.
  2. **Reiniciar:** Este comando instalará el subsistema de Linux y requerirá reiniciar el equipo.
  3. **Descargar Docker Desktop:** Ir a la página oficial de Docker y descargar el instalador para Windows (Docker Desktop .exe).
  4. **Ejecutar Instalador:** Correr el archivo .exe descargado y seguir los pasos. Docker Desktop proporciona una interfaz gráfica en Windows.
  5. **Verificar:** Una vez instalado y reiniciado, abrir Docker Desktop y verificar que funcione. Se puede probar con `docker ps` en la terminal de Windows (cmd o PowerShell).
- **Posibles Problemas en Windows:** Se mencionó que a veces Docker en Windows (vía WSL) asigna una IP diferente a la del computador host, lo que *podría* generar problemas de red al conectar con otros dispositivos (como el robot), aunque no siempre ocurre.
